# 职业规划砚台

面向 IT 从业者与转行者的**个性化职业规划** Web 应用。方法论固定，简历/背景只作为输入：先采集背景，再推荐可信的目标岗位，对照行业常见岗位要求做差距分析，最后给出按月计的保守学习与求职路径。

本仓库此前为 Python「智能体工作台 / 旅行规划 Agent」作品集，现已替换为本应用。历史提交仍可在 `git log` 中查看。

## 做什么、不做什么

- **做：** 把常见 IT 岗位（后端、前端、全栈、数据、算法、LLM 应用、Agent、DevOps/SRE、测试开发、技术 PM、移动端、安全）的典型要求结构化，并据此生成可执行计划。
- **不做：** 实时爬取招聘网站、预测薪资、虚构公司或统计数字、代替真实导师做决策。
- 岗位要求依据的是国内招聘平台（BOSS 直聘、拉勾、猎聘）与 LinkedIn / Indeed **同类 JD 的常见写法**，以及公开工程实践。页面里会写明「依据的是哪类来源」，而不是伪引具体雇主。

## 使用流程

1. **背景**：学历、年限、技术栈、城市、兴趣；可粘贴简历文本（v1 不做 PDF 解析）。
2. **目标岗位**：根据重叠度与兴趣给出建议，也可从 12 条 IT 轨道中自选。
3. **岗位要求**：硬技能、年限 Title、项目证据、来源类型。
4. **差距**：已具备 / 关键缺口 / 假设（背景偏薄时会明确标注）。
5. **路径报告**：4 个阶段，每阶段含目标能力、周级任务、验收标准、保守工期理由、行业先例，以及公开存在的文档/课程示例。报告含「可信度说明」与证据清单。
6. 可**更换目标岗位**重新生成；可把计划**下载/复制为 Markdown**。

进度保存在浏览器 `localStorage`，刷新页面不会丢失。无账号、无后端。

## 本地运行

需要 Node.js 18+（推荐 20/22）。

```bash
npm install
npm run dev
```

浏览器打开 [http://localhost:3000](http://localhost:3000)。

生产构建：

```bash
npm install
npm run build
npm start
```

## 技术栈

- Next.js（App Router）+ TypeScript
- Tailwind CSS（中文字体走系统栈：PingFang SC / 微软雅黑 / Noto Sans SC 等，不请求 Google Fonts）
- 纯前端：推荐、差距与规划都在本地计算

核心逻辑在 `lib/`：

| 文件 | 职责 |
| --- | --- |
| `lib/roles.ts` | 12 条岗位画像与典型要求 |
| `lib/suggest.ts` | 目标岗位建议 |
| `lib/gap.ts` | 差距分析 |
| `lib/plan.ts` | 分阶段路径与保守工期 |
| `lib/export.ts` | Markdown 导出 |
| `lib/storage.ts` | localStorage |

## 隐私

所有输入只留在本机浏览器，不会上传。清除站点数据即删除存档。

## 许可

个人学习与求职准备使用。岗位画像是归纳，不是任何招聘平台或雇主的官方数据。
